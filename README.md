# COMP-596-002---Project-1.0

# Requirements
* Python 3.7.4
* PyCharm
* arcade package - http://arcade.academy/

# How to Use
1. Clone repo to desired directory
1. Add directory as Project in Pycharm
1. Make sure the project interpreter is set to Python 3.7.4 and the arcade package is installed
1. Run

# Controls
* Space - Shoot
* W or Up Arrow - Up
* A or Left Arrow - Back
* S or Down Arrow - Down
* D or Right Arrow - Forward
